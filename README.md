# Exergism Commons Governance

This repository is the organization-level home for governance, contributor-rights, intellectual-property provenance, stewardship, and other cross-project institutional policies of **Exergism Commons**.

Project-specific legal, philosophical, analytical, and technical authority remains in the repository that owns that layer. Nothing in this repository silently changes an existing Exergism release, ECL Bundle, ECL Schedule, ECL-PL patent grant, or other immutable project artifact.

## Status

This repository is being bootstrapped. A policy is not operative merely because a draft exists here. Any legally consequential instrument must state its own version, adoption status, effective date, scope, and competent legal steward.

## Design constraints

Organization-level governance should preserve the ecosystem's existing separation of concerns:

- **Exergism** — canonical philosophical corpus and formal exergic-analysis model;
- **ECL** — experimental copyright/software-rights licensing and evidence-backed governance;
- **ECL-PL** — separate optional patent-licensing architecture;
- **organization governance** — cross-project stewardship, contributor provenance, institutional process, and shared policy.

Repository administration does not by itself transfer contributor copyright or patent rights to Exergism Commons.
